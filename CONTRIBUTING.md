# Как добавить гипотезу в Банк ЛАИ 🏛️

Спасибо за интерес к проекту! Чтобы наши данные оставались системными и полезными для анализа, пожалуйста, следуйте этим правилам.

## 1. Выберите правильный сегмент
Перед созданием файла откройте папку `hypotheses/SEGxx` и прочитайте файл `.index`, чтобы убедиться, что ваша тема подходит под критерии этого сегмента.

## 2. Используйте шаблон
Всегда начинайте с копии файла `КарточкаГипотезы_v12.json`. Не придумывайте новые поля, если они не согласованы с куратором.

## 3. Правила именования файлов
Файл должен называться строго по схеме:
`LAI_SEG{НомерСегмента}-{Автор}_{ПорядковыйНомер}.json`

*   **Пример:** `LAI_SEG04-Sergeev_01.json`
*   *Порядковый номер* уникален для каждого автора внутри одного сегмента.

## 4. Проверка связей
Если ваша гипотеза связана с другими, обязательно укажите их ID в поле `relationships`. Убедитесь, что файлы с этими ID уже существуют в репозитории.

## 5. Отправка изменений
1. Нажмите «Commit changes».
2. В описании кратко укажите суть гипотезы.
3. Создайте Pull Request (запрос на слияние), чтобы куратор мог проверить вашу карточку перед добавлением в основную базу.
