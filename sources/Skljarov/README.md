# Банк гипотез ЛАИ 🏛️
# lai(LAH)-hypothesis-bank
Этот репозиторий предназначен для систематизации и верификации гипотез участников Лаборатории Альтернативной Истории (ЛАИ). 
Цель проекта — перевести разрозненные идеи в строгий формат JSON-карточек, позволяющий отслеживать статус каждой гипотезы, проводить поиск, групповой анализ, устанавливать связи и корреляции между идеями выдвигаемыми различными авторами.

## Структура проекта
- **hypotheses/**: Папки с сегментами классификации (SEG01–SEG10).
- **templates/**: Шаблоны карточек и инструкции.
- **docs/**: Дополнительная документация.

Для добавления новой гипотезы используйте шаблон из файла `КарточкаГипотезы_v11.json`.
